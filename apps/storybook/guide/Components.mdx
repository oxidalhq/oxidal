# Components: which, when, when not

Every component in `packages/ui/src/components/ui`, with the rule for using it and the
product files it replaces. Read the container ladder first.

| Component                     | Use it for                                                                                                                                                      | Not for                                                                | Replaces in `apps/web`                                                           |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| Button                        | Actions. `default` for the one the screen is for; `outline` for the rest; `ghost` for nav and row actions; `destructive` for Delete/Remove; `link` in sentences | A state that stays (Toggle); a choice (Segmented, Select)              | `button.tsx`, `h-11 w-11 p-0` hacks, `.oxidal-button`                            |
| Toggle, ToggleGroup           | A state that stays until pressed again: bypass, mute, solo, loop, click                                                                                         | Navigation; settings that persist (Switch)                             | `LedToggle` (state part), `toggle-group.tsx`                                     |
| SegmentedControl              | One of two to five visible choices: List/Artwork, Serial/Parallel, display mode                                                                                 | More than five (Select); independent states (ToggleGroup)              | `toggle-group.tsx` single, `settings-tab` rows on phones                         |
| Switch                        | A setting that stays and saves when flipped: Protect, keep awake                                                                                                | Momentary or performance state                                         | `switch.tsx`                                                                     |
| Checkbox                      | Some of many; one acknowledgement                                                                                                                               | A single on/off setting (Switch)                                       | `checkbox.tsx`                                                                   |
| Select                        | One of six or more: device, channel, sample rate                                                                                                                | Thousands (Combobox); two to five (Segmented)                          | `select.tsx`                                                                     |
| Combobox                      | Find one of many by typing: a model, a preset, an effect to add                                                                                                 | Short lists (Select)                                                   | `ModelPicker` search, `AddBlockChooser` search, Library's preset search          |
| NumberField                   | A value where the number matters: gain, level, time, tempo. Drag or type                                                                                        | A value where the position matters (Slider)                            | `DragFader`, `TouchAdjust`, `.field` readouts                                    |
| Slider, fader                 | Position: block controls, master, stem levels (vertical)                                                                                                        | Exact numbers (NumberField)                                            | `slider.tsx`, `StemMixer` faders, `MasterLevel` control                          |
| Tabs                          | Sections of one workspace, underlined                                                                                                                           | Choices; on phones with more than four, a Select                       | `settings-tab`, `library-tabs`, `icon-tab`                                       |
| Badge, Led                    | A small fact: category, count, Playing, Unsaved, Selected                                                                                                       | Anything clickable                                                     | `badge.tsx`, `media-chip`, `oxidal-chip`, `stem-chips`, `StateChip`, `chain-led` |
| Text styles                   | Caption, Eyebrow (small caps), Label, Readout, Title                                                                                                            | Body text (plain `p`)                                                  | `.caption` (281 uses), `.eyebrow`, `page-heading`                                |
| Separator                     | A rule between groups, with or without a label                                                                                                                  | Layout spacing (use gap)                                               | one-off `border-top` rules                                                       |
| Card                          | A panel on the page: a tool, a form section, a summary                                                                                                          | Lists (List); floating surfaces                                        | `instrument-surface`, `rig-builder-*` panels, `Alert` for recoverable errors     |
| List, ListRow                 | Similar things in a column, each a touch target, with leading/trailing slots                                                                                    | Tables of numbers (a table)                                            | `MediaRow`, `LibraryRow`, `stem-song`, `ToolRow`                                 |
| Tooltip                       | The name of an icon-only control on hover/focus                                                                                                                 | Touch-only hints; actions; long text (Popover)                         | `title=` attributes                                                              |
| Popover                       | A short choice or small form in context: add block, sort, scene name                                                                                            | Many controls (Sheet); a blocking decision (Dialog)                    | `SlotChooser`, sort selects, inline rename forms                                 |
| DropdownMenu                  | The actions on one thing, destructive last                                                                                                                      | Choosing a value (Select)                                              | `MoreMenu`, `SetListMenu`                                                        |
| Dialog                        | A decision that must be answered before going on                                                                                                                | Editing with context (Sheet); anything that can be inline              | `dialog.tsx`, `AdjustmentDialog`, `SettingDialog`, `NativeSplitDialog`           |
| useConfirm                    | Two answers, Cancel safe and focused first; `destructive` for removals                                                                                          | Multi-step forms                                                       | `confirm.tsx`                                                                    |
| Sheet                         | Edit many controls while the screen stays visible; bottom on phones, side on laptops                                                                            | Decisions (Dialog); whole workspaces (page)                            | `RigSheet`, `PlayerSheet`, `StemsSheet`, tuner overlay                           |
| NoticeTray, useNotice, notify | App-wide state notices and one-off toasts, in one place                                                                                                         | Section errors (Card with a recovery button); form validation (inline) | `NoticeTray`, `notices.ts`, `media-note` alerts, `RecoveryNotice`                |
| ScrollArea                    | A region that scrolls inside a fixed surface                                                                                                                    | The page                                                               | ad hoc `overflow: auto`                                                          |
| Collapsible                   | Detail most people do not need: Advanced, Details, help                                                                                                         | Hiding the primary action                                              | raw `<details>` in Settings and failures                                         |
| Skeleton, Loading             | Loading: the shape of what is coming; or one line after 300 ms                                                                                                  | Progress with a known fraction (Progress)                              | `loading.tsx`, `Reading…` strings                                                |
| EmptyState                    | Nothing here yet, one sentence, one action                                                                                                                      | Errors                                                                 | inline `caption` sentences, `StateNotice` empty                                  |
| Progress, StepProgress        | Work with a fraction, or in known steps with Cancel                                                                                                             | Indeterminate waits under a second                                     | `steps.tsx`, `stem-bar`, `UploadQueue` bars                                      |

## Writing the component

One file per component in `packages/ui/src/components/ui/<name>.tsx`, its variants in
`cva`, `data-slot` on the root, `cn()` last so callers can override, and
beside it `<name>.stories.tsx` with a story per state and `<name>.test.tsx`
for behaviour (keyboard, touch, announcements). `pnpm a11y` runs axe over
every story of the built Storybook; it must pass.
