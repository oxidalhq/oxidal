# Oxidal Wah

Oxidal Wah is an original Rust LV2 resonant filter with Position, Resonance,
Range and Mix controls. It provides mono and stereo bundles and is intended to
sit before drive or amp processing. Its controls are ordinary LV2 values, so a
scene can sweep or recall them like any other rig block.

- **Bundle:** `oxidal-wah.lv2`; binary `oxidal_wah.so`; no added latency.
- **URIs:** `urn:oxidal:plugin:wah#mono` and `#stereo`.
- **Source:** `crates/oxidal-wah`; original code and no third-party DSP.
- **References:** [`crates/oxidal-wah/REFERENCES.md`](../crates/oxidal-wah/REFERENCES.md).
