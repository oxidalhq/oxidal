# Sources and references — Oxidal Bloom

Written for Oxidal from the published descriptions named here. No third-party
source code was copied, ported or used as a base. See
[the clean code rule](../../docs/native-effects.md).

| Part                              | What it is                                                                 | Source                                                                                                                                                                                                  | Constants                                                                                                                                                                                                          |
| --------------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Entry point                       | `oxidal_lv2_plugin::export!`                                               | Oxidal's plugin interface crate                                                                                                                                                                         | None                                                                                                                                                                                                               |
| Network (`network.rs`)            | Eight-line feedback delay network with an energy-keeping mix               | Jot and Chaigne (1991) [1]; Schlecht and Habets (2017) [2]                                                                                                                                              | Line lengths: a shortest and longest time per mode chosen here, spread geometrically in sevenths, each rounded up with `prime_at_or_above`                                                                         |
| Absorption (`parts.rs`)           | Per-line gain and one-pole shelf set from the decay time                   | Jot and Chaigne (1991) [1], absorptive filters: gain `10^(−3·length/RT60)` per line; the shelf's bound (gain never above the low-band gain) derived here from the circle a first-order high-pass traces | Corner and high-band ratio are functions of Tone chosen here                                                                                                                                                       |
| All-pass diffuser (`parts.rs`)    | Schroeder all-pass; inside a loop its delay carries the loop's attenuation | Schroeder (1962) [3]; attenuating every delay unit alike, Jot and Chaigne (1991) [1]                                                                                                                    | Lengths per mode chosen here, rounded up to primes; gains 0.3 to 0.7 chosen here                                                                                                                                   |
| Fractional read (`parts.rs`)      | Third-order Lagrange interpolation                                         | Lagrange polynomial through four points, from its definition; passivity checked numerically (gain at most one for every fraction)                                                                       | Weights follow from the definition                                                                                                                                                                                 |
| Crossfading tap (`parts.rs`)      | A delay length changes by crossfade                                        | Own design: a convex blend of two taps with the cubic `3t² − 2t³`                                                                                                                                       | 40 ms fade chosen here                                                                                                                                                                                             |
| Early reflections (`network.rs`)  | Six first reflections per ear                                              | Image-source method: Allen and Berkley (1979) [4], first order only                                                                                                                                     | Box 1.6 : 2.3 : 1 with height 2.4 to 6 m, source and listener positions and wall loss 0.8 chosen here; speed of sound 343 m/s                                                                                      |
| Coupled mix, Bloom (`network.rs`) | Two four-point Hadamard mixes joined by a rotation                         | Hadamard matrix from its definition; a plane rotation keeps energy; coupled-volume energy exchange worked out here (`time constant = mean loop time / (2·share)`)                                       | Share from Build; none fixed                                                                                                                                                                                       |
| Pitch shifter (`shifter.rs`)      | Two crossfaded taps on a delay line read at a changed rate                 | Zölzer (ed.), _DAFX: Digital Audio Effects_ [5], delay-line pitch shifting                                                                                                                              | Grains of 80 and 66 ms, window `3t² − 2t³` and band limit 6.5 kHz chosen here; fifth is `2^(7/12)`                                                                                                                 |
| Shimmer insertion (`network.rs`)  | Part of two lines passes through the shifters by a sine and cosine blend   | Own design from energy conservation (`cos² + sin² ≤ 1`, rounded down)                                                                                                                                   | Largest shifted share 0.7 chosen here                                                                                                                                                                              |
| Plate (`plate.rs`)                | Figure-of-eight tank                                                       | Dattorro (1997) [6], the plate reverberator figure and its table of output taps                                                                                                                         | Delay and all-pass lengths, all-pass gains, excursion, output tap positions and output gain 0.6 are the paper's, scaled from 29,761 Hz. Per-section decay gains replace the paper's single decay gain (derivation) |
| Spring (`spring.rs`)              | Delay loop with a chain of stretched first-order all-passes                | Välimäki, Parker and Abel (2010) [7], low-frequency chirp structure; Parker and Bilbao (2009) [8]                                                                                                       | 64 stages, coefficients 0.62 and 0.66, periods 43 and 61 ms and the 4 kHz transition chosen here from the group delay `(1 − a²)/(1 + 2a·cos ω + a²)`; Butterworth Q from the pole angles                           |
| Nonlinear (`nonlinear.rs`)        | Multi-tap delay with shaped tap gains                                      | Own design; tap positions drawn from `oxidal_dsp::Noise`                                                                                                                                                | 32 taps a side; shapes `1`, `t²`, `sin²(πt)` chosen here                                                                                                                                                           |
| Freeze                            | Loop gains move to exactly one, input closed, modulation stopped           | Lossless feedback delay network (Schlecht and Habets (2017) [2])                                                                                                                                        | None                                                                                                                                                                                                               |
| Levels                            | Input trim per mode and a fourth-root trim against decay time              | Measured on this code with tilted noise                                                                                                                                                                 | Measured                                                                                                                                                                                                           |
| Test FFT (`tests/support/mod.rs`) | Radix-2 fast Fourier transform                                             | Cooley and Tukey (1965) [9], from the definition                                                                                                                                                        | None                                                                                                                                                                                                               |
| Decay measure (`tests/support/…`) | Backward integration of the squared response                               | Schroeder (1965) [10]                                                                                                                                                                                   | None                                                                                                                                                                                                               |
